VOICE AI ASSISTANT

EVELYN

Evelyn Voice AI Assistant

2026.04 - Present
Summary

Discord 기반 한국어 음성 AI 캐릭터 프로젝트입니다.

Role

STT, LLM, TTS, memory 흐름을 연결하고 개선했습니다.

Key Features
  • 실시간 음성 입출력
  • LLM routing과 캐릭터 응답
  • turn_trace 기반 지연 로그 점검
Results

첫 토큰, 첫 PCM, STT 완료 후 TTS 출력까지의 체감 지연을 다시 측정했습니다.

Performance Baseline

31ms 첫 토큰 보통
618ms 첫 PCM 보통
1.18s STT 후 TTS 출력

첫 토큰은 EXAONE streaming SSE의 첫 non-empty token까지, 첫 PCM은 OmniVoice streaming PCM의 첫 audio chunk까지입니다. STT 후 TTS 출력은 STT가 끝난 뒤 Main LLM 응답이 완료되고 TTS 첫 PCM이 나올 때까지입니다.

## 검색의 준비 비용과 파생 상태

- 태그 유실·오염 실험에서는 평가 정답을 관측 태그와 분리했다. 그래야 태그가 없어졌다고 정답까지 지워 통과시키지 않는다. 새 자료의 실제 검색 비교에서 근거/필드 부재, 거짓 태그의 제외 조건, 점수 계산 뒤 순위 탈락을 나눠 확인했다. 속도 개선과 의미 규칙의 결정은 별개이며, 정해진 검증을 끝냈다고 새 정책까지 자동 승인하지 않았다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P41 전체 조합·독립 검산. 운영 반영은 아니다.

- 색인 단독 이득을 실제 검색 경로에서도 다시 비교했다. 현재 행·권한·삭제·결과 순서를 보존한 역색인은 큰 본문 조건에서 비용을 줄였지만 작은 조건에서는 이득이 없었고, 태그 오염에 따른 순위 실패도 그대로였다. 자료구조의 속도, 전체 경로 비용, 결과의 의미적 품질을 따로 판정해야 한다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P40 교차 측정·독립 검산. 합성 조건의 결과이며 운영 채택은 아니다.

- 기존 전문검색 색인과 최종 판정기의 토큰 경계가 다르면, 후보 수 제한을 없애도 정답을 잃을 수 있었다. 같은 canonical token을 표현하도록 기존 자료구조를 재사용하고, 새 합성 자료에서 생성·갱신·조회 비용까지 비교했다. 역색인은 완전한 후보 집합을 보존하며 이 유한 작업량의 비용을 줄였지만, 색인 단계의 이득을 전체 검색 속도로 해석하지 않았다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P39 재현·비교·독립 검산. 문자열 일치·권한 검사·의미적 관련성은 별도 책임이며 운영 통합은 미완료다.

- 검색 후보를 먼저 제한하면 뒤의 정확한 필터가 정답을 복구할 수 없다는 반례를 실제 합성 조회로 확인했다. 누락 후보를 완전 검사로 보완해 정확성 기준선을 만든 뒤, 그 비용과 태그 오염에 따른 별도 순위 실패를 분리했다. 실행 간 기준선 속도까지 달라졌으므로 시간 차이를 곧바로 최적화 효과로 해석하지 않고 동일 실행 교차 비교로 이어간다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P36–P38. 운영 반영이나 최적해 확정은 아니다.

- 파일 사전 읽기와 실행 순서를 교차해 실제 검색을 비교했다. 사전 읽기 뒤의 조회만 빨라져도 목록 탐색·읽기 비용까지 포함하면 대부분의 조건에서 이득이 사라졌다. 명시적 준비가 없는 조건을 콜드 상태라고 부르지 않고, 조건별 관측과 일반적인 성능 보장을 구분했다. 근거: Evelyn `plan.md`, `docs/worklog/2026-09-13.md`의 P26 합성 실험·독립 검산.
- 더 단순한 색인 연결 방법을 검토하다가 같은 파일의 ID 변경 후 이전 ID의 파생 행이 남는 경우를 실제 동기화로 재현했다. 현재 응답에 이전 ID가 직접 노출되는지와 저장 상태가 일치하는지는 별개였다. 속도 최적화 전에 기존 오염 복구·새 오염 예방·트랜잭션과 버전 갱신을 함께 검증하는 방향으로 이어갔다. 근거: 같은 프로젝트 기록의 P27 재현과 P28 검증 범위. 운영 수정 완료를 뜻하지 않는다.
- 격리된 교정 후보는 독립 검사에서 기존 오염 복구와 새 오염 예방, 실패 시 롤백, 실제 조회의 권한·삭제 경계를 통과했다. 무변경 조회 비용은 실험용 설치 비용까지 포함해 추가 측정했다. 두 기능을 함께 적용할 때는 개별 통과로 대신하지 않고, 조합 상태에서 중간 실패·전체 롤백·정상 재시도를 별도로 검증했다. 정확성 개선과 성능 비용을 별도 판정하고, 합성 검증을 운영 반영 완료로 취급하지 않았다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P28–P29.
- 출처·소유권·삭제 검사가 통과해도 질문에 관련된 기억을 찾았다는 뜻은 아니었다. 독립 사실을 둔 합성 질문으로 없는 정답에도 결과를 채우는 동작과 과도한 태그가 본문 정답을 밀어내는 사례를 확인했다. 고정 목록에 정답이 우연히 포함된 것을 별칭 이해로 세지 않고, 안전성·관련성·속도를 나눠 평가한다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P30 실제 조회 및 독립 검산.
- 그 근거로 네 가지 검색 허용 조건을 고정하고 새 합성 데이터에서 재검증했다. 엄격한 일치는 무관한 결과를 크게 줄였지만 별칭·조사 질문의 정답도 놓쳤다. 오답 감소만으로 최적이라고 결론 내리지 않고 정답 손실과 추가 비용을 함께 남겼다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P31 고정 후보 비교·독립 검산. 운영 반영은 하지 않았다.
- 짧은 키워드에서 자연문장으로 평가를 넓히자, 모든 단어 일치는 질문용 표현 때문에 정답을 버리고 일부 일치는 같은 표현을 가진 무관한 기록을 골랐다. 태그에 있는 단어만 남겨도 필수·선택·제외 조건이 같은 토큰 집합으로 합쳐질 수 있었다. 자료구조 비교 전에 질의의 의미가 전달되는 경계를 확인해야 한다는 반례를 얻었다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P32 합성 실제 조회·독립 검산 및 토큰 투영 대조. 실제 모델의 의미 해석을 검증한 것은 아니다.
- 제한된 질의 해석 후보는 조건을 구분해 거짓 반환을 줄였지만, 해석기와 실제 검색기의 토큰 경계가 다르면 제외 조건까지 무력해질 수 있었다. 독립 검토로 이 경계를 교정하고 벡터 상위 결과와 지연 계산 양쪽에 같은 질의가 들어가는지 확인했다. 개발 자료의 개선과 인용 의미·근거 없는 별칭의 잔여 실패, 추가 실행 비용을 함께 기록했다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P33. 일반 언어 이해나 운영 최적화를 완료한 것은 아니다.
- 새 자료에서 확인한 태그 오염을 근거로 본문·메타데이터·양쪽의 허용 조건을 다시 교차 비교했다. 본문 조건은 오염을 줄였지만 태그에만 있는 올바른 별칭을 놓쳤고, 메타데이터 조건은 태그가 빠진 기록을 놓쳤다. 평균 개선만 보지 않고 반대 방향의 양성 사례와 미지원 문장 fallback을 함께 평가했다. 근거: Evelyn `docs/worklog/2026-09-13.md`의 P34–P35 합성 실험. 보편적인 최적 정책을 확정한 것은 아니다.

## AIRI 재사용 설계 검토

- 기존 설정 안내와 실제 출력 음량 표현 두 후보로 설계를 좁혔다. 게임·음성 제어는 기존 구현과
  계획에 매핑해 중복 엔진을 피했다. 검토용 초안이며 구현·실환경 검증 결과는 아니다.
- 재사용 판단은 기능 이름보다 실제 입력·출력 경계를 먼저 비교해야 한다. 오디오 write 완료는
  스피커 청취 증거가 아니며 시험 재생 접수도 실행 완료와 다르다. 이 차이를 수용 기준에 반영했다.
- 원본: Evelyn `plan.md` P1-9, `docs/superpowers/specs/2026-09-04-airi-selective-reuse-design.md`,
  `docs/worklog/2026-09-05.md`. 다음 검토는 표현 개선의 가치와 지연·통신 비용·장치 검증 부담이다.
- 반복 설계 검토에서는 출력 오류와 표시 오류, 정상 종료와 취소, 요청 처리 순번과 표시 순번을
  구분했다. 지연 수치와 누락률을 함께 봐야 아무것도 표시하지 않는 동작이 품질 검사를 통과하지 않는다.
  수정 후 독립 문서 재검토를 마쳤으며 실제 UI·장치·성능 검증은 별도로 남는다.
- 후속 요구 확인으로 목표를 사이트에서 켜고 끄는 데스크톱 캐릭터로 바로잡았다. 사이트 종료 후
  유지와 더블클릭 복귀를 설계에 기록했다. 내부 설계의 정합성 검토와 사용자가 원하는 경험의
  확인은 별개다. 위 L/U 순서는 보류하고 동일 P1-9 원본 §0에서 설계를 계속한다.

## AIRI Minecraft 격리 준비와 증거 경계

- 공식 원본 `05007ce3`의 Minecraft와 전이 workspace만 분리하고 Node 24의 native 모듈,
  지원 패키지 빌드·import를 확인했다. 원본 테스트는 31개 통과·4개 실패였으며 지도 행 배열 공유
  결함을 숨기거나 원본 알고리즘을 바꾸지 않았다.
- 정식 실행 승인 경로에서 실제 서버 접속·물리 tick을 확인했다. 첫 모델 요청은 원본 입력이
  모델 context 한도를 넘어 실패했으며 이동·피격 비교는 미검증이다. 실험 프로세스는 종료했다.
- 이벤트의 처리 완료는 모델 응답 성공과 다르다. 원본 구성요소를 재사용할 때는 초기 시스템
  프롬프트까지 포함한 모델 입력 예산을 확인하고, 연결·판단·행동의 증거를 각각 판정한다.
- 동일 tokenizer의 고정 입력 비교로 역할 설명과 실행 API 안내의 비용을 분리했다. 프롬프트의
  예제가 실제 도구 schema와 어긋날 수 있으므로 긴 지침 자체를 기능 완성도의 증거로 보지 않는다.
- 후속 설계는 프롬프트 본문·반복을 보존하고 코드 생성과 기존 실행부를 연결하는 작은 어댑터로
  좁혔다. CLI에 메시지 본문을 전달하는 것과 원래 chat API 역할을 보존하는 것은 다르며,
  읽기 전용 실행 옵션만으로 도구가 없음을 입증할 수 없다. 구현·실환경 검증 전 설계 기록이다.
- 일반 대화 비교에서는 고정 성격 문구와 감정·표현 지침을 따로 측정하고, 실제 입력 경로별
  성격 정보 주입과 문맥 절단을 추적했다. 설정 파일의 긴 문구보다 요청까지 살아남는 정보가
  중요하다. 프롬프트 수정이나 대화 품질 실험을 수행했다는 기록은 아니다.
- 원본: Evelyn `plan.md` P1-7, `docs/worklog/2026-09-05.md`. 상세 실행 자료는 프로젝트에만 둔다.

## Main 성격 전달과 복원 경계 수정

- 기존 성격 지침을 일반 대화의 공통 조립 단계로 옮기고, 복원한 대화에 현재 시스템 지침을
  적용하도록 수정했다. 합성 회귀와 독립 검토를 통과했으며 실제 말투·지연·운영 적용 증거와 구분했다.
- 새 문맥 구역을 추가할 때는 화면에 보이는 문구뿐 아니라 stable prefix·캐시 구분도 함께 검증해야 한다.
  정체성 파일 읽기는 상태 생성과 분리하고, 손상된 파일의 fallback이 원본을 덮어쓰지 않도록 검사했다.
- 원본: Evelyn `CURRENT_EVELYN_PIPELINE.md`, `plan.md`, `docs/worklog/2026-09-05.md`.
  개인 프롬프트·대화·실행 자료는 이 공개 기록에 포함하지 않는다.

## AIRI 재사용 설계 검토

- 기존 설정 안내와 실제 출력 음량 표현 두 후보로 설계를 좁혔다. 게임·음성 제어는 기존 구현과
  계획에 매핑해 중복 엔진을 피했다. 검토용 초안이며 구현·실환경 검증 결과는 아니다.
- 재사용 판단은 기능 이름보다 실제 입력·출력 경계를 먼저 비교해야 한다. 오디오 write 완료는
  스피커 청취 증거가 아니며 시험 재생 접수도 실행 완료와 다르다. 이 차이를 수용 기준에 반영했다.
- 원본: Evelyn `plan.md` P1-9, `docs/superpowers/specs/2026-09-04-airi-selective-reuse-design.md`,
  `docs/worklog/2026-09-05.md`. 다음 검토는 표현 개선의 가치와 지연·통신 비용·장치 검증 부담이다.
- 반복 설계 검토에서는 출력 오류와 표시 오류, 정상 종료와 취소, 요청 처리 순번과 표시 순번을
  구분했다. 지연 수치와 누락률을 함께 봐야 아무것도 표시하지 않는 동작이 품질 검사를 통과하지 않는다.
  수정 후 독립 문서 재검토를 마쳤으며 실제 UI·장치·성능 검증은 별도로 남는다.

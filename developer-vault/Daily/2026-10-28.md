# 2026-10-28

## Evelyn LoRA 데이터·설정 준비

사용자 재개 승인 범위인 데이터 분리와 설정 준비만 진행했다. 기존 추론 설치가 LoRA 설정을 지원하지 않는 차이를 반영해 공식 지원 revision에 맞춘 설정과 소스 전용 사전검사를 준비했고, 현재 실행은 차단 상태로 구분했다. 설정 산출물 지문 일치를 확인했으며 모델·서비스를 켜지 않았다. [[Learnings/Evidence scope is part of the result]]와 [[Learnings/External effects need exact ownership and receipts]]를 준비/실행 구분과 원본·산출물 결속에 적용했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-lora-preparation-20261028`이다. 데이터 분리와 독립 검토는 진행 중이며 다음 checkpoint는 최종 개수·길이·누출/원본 보존 확인이다. 실제 학습·토큰화·GPU 호환성·품질은 미검증이다.

## Evelyn 음성 작업 모델 종료

사용자 요청에 따라 음성 검사 세 묶음의 연결 서버와 모델 엔진 총6개를 정상 종료하고 실제 종료·관련 포트 해제를 확인했다. 이미 내려간 TTS를 다시 건드리지 않았으며 데이터·가중치·Docker 자체는 유지했다. LoRA 학습 준비는 읽기 단계에서 보류했고 실제 학습은 하지 않았다. [[Learnings/External effects need exact ownership and receipts]]와 [[Learnings/Evidence scope is part of the result]]를 종료 대상 확인과 준비/실행 구분에 적용했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-model-unload-20261028`이며 다음 checkpoint는 재개 시 설치 버전의 LoRA 지원 경계를 확인하고 학습/검증 목록과 설정을 준비하는 것이다. 재시작·학습·음질은 이번 확인 범위가 아니다.

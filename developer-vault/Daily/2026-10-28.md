## Evelyn LoRA 유사도 저하 진단

[[Learnings/Evidence scope is part of the result]]를 적용해 조건 차이와 인과 증명을 구분했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-lora-cause-analysis-20261028`이다. 추가 음성 생성·학습·서비스 변경·사람 청취 수용은 하지 않았다. 다음은 재학습 전에 기존 체크포인트와 조건을 분리한 최소 추론 비교다.

## Evelyn LoRA 실행 환경 확인

후속 실행 승인에 따라 기존 추론 설치를 변경하지 않는 별도 학습 이미지에 공식 LoRA 지원 코드를 설치했다. 실제 소스 지문·의존성·단일 RTX 5090 연산과 소유 합성 파일의 읽기 전용/네트워크 차단을 확인했고, 원본 목록을 보존한 학습용 Linux 경로 재매핑을 마쳤다. 기존 사용자 폴더 접근권한과 WSL의 GPU 열거 차이를 실제 관측해 소유 사용자와 명시 장치 선택으로 해결했다. 이어 9263개 전부 토큰화하고 학습8813/검증450의 원목록·결과 연결과 누락/중복/길이필터 제외0을 확인했다. 실제 학습 이미지의 합성25검사, 환경·토큰·짧은 실제 저장/재개 독립검토를 통과했다. 학습 대상은 전체의 약4.20%였으며 모델·optimizer·학습률스케줄러·난수·설정의 저장/복원 상태 동등성을 확인한 뒤 원3000단계 설정으로 본학습을 새로 시작했다. 13:19:54에 약29분 만에3000단계를 정상 종료한 사실을13:40 발견하고13:44 최종 대조했다. 모든 단계의 loss/gradient가 유한했고 실행오류·메모리부족 종료0, 검증12회 중 최종loss3.221455가 관측최저였다. 고유checkpoint12개의 저장기록·필수파일을 확인했으며 감시 요청 시 이미 종료되어 새 예약을 만들지 않았다. [[Learnings/External effects need exact ownership and receipts]]와 [[Learnings/Evidence scope is part of the result]]를 전용 실행 범위와 설치/학습/품질 구분에 적용했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-lora-execution-20261028`이다. 학습은 완료했지만 최종 어댑터 재로드·음질청취·운영교체는 하지 않았고, upstream의 데이터 읽기 위치 복원 미지원 한계는 유지한다. 다음 checkpoint는 별도 승인된 최종 음질 평가다.

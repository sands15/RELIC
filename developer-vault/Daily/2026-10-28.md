# 2026-10-28

## Evelyn LoRA 데이터·설정 준비

사용자 재개 승인 범위에서 합격9263쌍을 원본 참조 방식으로 학습8813쌍·검증450쌍으로 나눴다. 합계20시간2분33.59초와 원본 파일 지문·수정 시각을 보존했고 같은 문장군이 양쪽에 걸치지 않음을 확인했다. 첫 후보의 검증 유형 편중은 군을 쪼개지 않는 한 번의 재배분으로 보정했다. 기존 추론 설치의 LoRA 미지원 차이를 반영해 공식 지원 revision에 맞춘 설정·소스 전용 사전검사를 준비했으며 데이터/설정의 같은 독립 검토와 최종 수치 대조까지 통과했다. [[Learnings/Evidence scope is part of the result]]와 [[Learnings/External effects need exact ownership and receipts]]를 준비/실행 구분과 원본·산출물 결속에 적용했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-lora-preparation-20261028`이다. 모델·서비스 OFF를 최종 재확인했고 요청된 파일 준비는 완료했다. 실제 환경 구축·학습·토큰화·GPU 호환성·품질은 미검증이며, 다음 실행은 해당 범위 승인 후 별도로 다룬다.

## Evelyn LoRA 실행 환경 확인

후속 실행 승인에 따라 기존 추론 설치를 변경하지 않는 별도 학습 이미지에 공식 LoRA 지원 코드를 설치했다. 실제 소스 지문·의존성·단일 RTX 5090 연산과 소유 합성 파일의 읽기 전용/네트워크 차단을 확인했고, 원본 목록을 보존한 학습용 Linux 경로 재매핑을 마쳤다. 기존 사용자 폴더 접근권한과 WSL의 GPU 열거 차이를 실제 관측해 소유 사용자와 명시 장치 선택으로 해결했다. 이어 9263개 전부 토큰화하고 학습8813/검증450의 원목록·결과 연결과 누락/중복/길이필터 제외0을 확인했다. 실제 학습 이미지의 합성25검사, 환경·토큰·짧은 실제 저장/재개 독립검토를 통과했다. 학습 대상은전체의약4.20%였으며모델·optimizer·학습률스케줄러·난수·설정의저장/복원상태동등성을확인한뒤원3000단계설정으로본학습을새로시작했다. [[Learnings/External effects need exact ownership and receipts]]와 [[Learnings/Evidence scope is part of the result]]를 전용 실행 범위와 설치/학습 구분에 적용했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-lora-execution-20261028`이다. 본학습의실제첫스텝진행은확인했지만최종학습·음질은미완료이며,upstream의데이터읽기위치복원미지원한계는유지한다. 다음checkpoint는첫본학습저장과최종실행결과다.

## Evelyn 음성 작업 모델 종료

사용자 요청에 따라 음성 검사 세 묶음의 연결 서버와 모델 엔진 총6개를 정상 종료하고 실제 종료·관련 포트 해제를 확인했다. 이미 내려간 TTS를 다시 건드리지 않았으며 데이터·가중치·Docker 자체는 유지했다. LoRA 학습 준비는 읽기 단계에서 보류했고 실제 학습은 하지 않았다. [[Learnings/External effects need exact ownership and receipts]]와 [[Learnings/Evidence scope is part of the result]]를 종료 대상 확인과 준비/실행 구분에 적용했다. 원본은 `docs/worklog/2026-10-28.md#omnivoice-model-unload-20261028`이며 다음 checkpoint는 재개 시 설치 버전의 LoRA 지원 경계를 확인하고 학습/검증 목록과 설정을 준비하는 것이다. 재시작·학습·음질은 이번 확인 범위가 아니다.

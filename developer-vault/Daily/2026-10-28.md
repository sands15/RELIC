## Evelyn LoRA 실행 환경 확인

후속 실행 승인에 따라 기존 추론 설치를 변경하지 않는 별도 학습 이미지에 공식 LoRA 지원 코드를 설치했다. 실제 소스 지문·의존성·단일 RTX 5090 연산과 소유 합성 파일의 읽기 전용/네트워크 차단을 확인했고, 원본 목록을 보존한 학습용 Linux 경로 재매핑을 마쳤다. 기존 사용자 폴더 접근권한과 WSL의 GPU 열거 차이를 실제 관측해 소유 사용자와 명시 장치 선택으로 해결했다. 이어 9263개 전부 토큰화하고 학습8813/검증450의 원목록·결과 연결과 누락/중복/길이필터 제외0을 확인했다. 실제 학습 이미지의 합성25검사, 환경·토큰·짧은 실제 저장/재개 독립검토를 통과했다. 학습 대상은 전체의 약4.20%였으며 모델·optimizer·학습률스케줄러·난수·설정의 저장/복원 상태 동등성을 확인한 뒤 원3000단계 설정으로 본학습을 새로 시작했다. 13:19:54에 약29분 만에3000단계를 정상 종료한 사실을13:40 발견하고13:44 최종 대조했다. 모든 단계의 loss/gradient가 유한했고 실행오류·메모리부족 종료0, 검증12회 중 최종loss3.221455가 관측최저였다. 고유checkpoint12개의 저장기록·필수파일을 확인했으며 감시 요청 시 이미 종료되어 새 예약을 만들지 않았다.

# 2026-11-05

## Evelyn TTS 요청에 한국어 지정과 seed 고정

TTS 품질이 들쑥날쑥하다는 신고(문장마다 톤이 달라짐, 발음 뭉개짐·모음 늘어짐)를 코드로 따라가 보니, 10-29 마음 전환 때 TTS 요청에서 `language: "ko"`가 빠져 있었다. 또 모든 문장이 seed 없는 무작위 생성이었다. 마음이 문장마다 `ko`와 고정 seed를 보내고, OmniVoice 패치가 생성 직전에만 난수를 고정한 뒤 되돌리도록 바꿨다. source 시험은 실제 HTTP 본문과 패치된 서버 코드, 실제 torch의 같은 seed→같은 잡음을 확인했고 관련 회귀 1,585개에서 실패 0이다. 이미지 재빌드·실제 생성·청취는 아직이다. 원본은 프로젝트 `docs/worklog/2026-11-05.md#tts-language-seed-20261105`.

재사용 가능한 교훈: (1) 클라이언트를 새로 쓰면 옛 클라이언트가 보내던 요청 필드를 하나씩 대조한다. 서버가 모르는 필드를 조용히 무시하거나 선택 필드가 빠져도 오류 없이 품질만 떨어지는 경우, 시험은 통과하고 귀로만 드러난다. (2) seed 고정은 재현성을 주지만 길이가 다른 문장끼리 같은 잡음을 공유하게 하지는 않는다. 문장 사이 톤 차이에 대한 효과는 기대가 아니라 측정 대상으로 둔다.

다음 확인: 승인 뒤 TTS 재빌드·재시작, 같은 문장 두 번 생성의 PCM 동일 여부, 실제 답변 청취.

# 2026-10-29

## Evelyn Mind 재설계 브레인스토밍·0~1단계

"항상 생각·들으며 준비·기능 마비를 Main이 바로 인지" 요구를 기존 구조 수정이 아닌 처음부터의 재설계로 다뤘다. 마음(판단 프로세스) 하나·몸(I/O 어댑터) 여럿·이벤트 중심의 draft 제안을 썼고 1·2절은 승인, 몸/자원/테스트 절은 검토 대기다. 기존 코드를 건드리지 않는 새 패키지에 이벤트 버스·revision·content-free 저널·6개 능력 장부·행동 관문·결정적 재생 검사를 구현해 53검사 PASS(source/offline, 런타임 미연결, 미커밋). 같은 날의 확장 동결 결정과 겹쳐 사용자에게 확인했고, 사용자는 0~1단계만 동결의 예외로 두는 결정을 승인했다. 2단계 이후는 음성 루프 실사용 PASS 또는 명시 재지정 뒤에만 연다. 출처: Evelyn `docs/worklog/2026-10-29.md#evelyn-mind-stage01-20261029`, `docs/superpowers/specs/2026-10-29-evelyn-mind-architecture-design.md`.

재사용 가능한 교훈: 연속 실패를 "시간 창 안의 trailing 개수"로만 판정하면 창이 지나는 것만으로 성공 없이 정상으로 복귀한다. 임계 초과는 latch로 고정하고 성공만 해제하며, 시간은 probe 허용만 열어야 fail-closed가 유지된다.

사용자가 개편 완료까지 제품을 쓰지 않겠다고 밝혀 전 단계 진행과 옛 경로 토글 없음을 결정으로 기록했다. writing-plans 형식의 1~2단계 계획을 먼저 쓴 뒤 그대로 실행해 Control Page 읽기 전용 능력 줄과 마음 쪽(대화·기관·transport·몸 허브·숙고기·조립·WebSocket 몸 서버)을 8개 커밋으로 남겼고 `tests/mind` 101검사 PASS(source/offline, 가짜 몸·모델 끝-끝 재생 PASS)다. 3·4단계 초안(상황 모델·예측기)에도 17검사를 붙여 PASS. 실제 장치·live는 NOT_RUN. 출처: Evelyn `docs/worklog/2026-10-29.md#evelyn-mind-stage01-20261029`, `docs/superpowers/plans/2026-10-29-evelyn-mind-stage1-2.md`.

재사용 가능한 교훈: 브레인스토밍 뒤 바로 코드를 쓰면 안 되고 구현 계획(테스트 먼저·완전한 코드·실행 명령)을 거쳐야 한다. 실제로 계획 단계에서 숙고기의 문장 절단·몸 서버 종료 뒤 상태 같은 기대값 오류를 미리 잡았다.

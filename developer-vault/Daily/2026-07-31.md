# 2026-07-31

## [[Projects/Evelyn|Evelyn]]

### 결과

- 대화 checkpoint에 hash/generation head를 도입해 rollback·삭제·손상 복구를 fail-closed하게 만들었다.
- 외부 전달이 끝난 답변을 즉시 durable commit하고 공개 오류에서 예외 원문·경로·민감정보를 제거했다.
- Minecraft의 HTTP liveness와 실제 기능 준비도를 분리하고 lease, runner, telemetry, 연결, task contract와 effect observer가 모두 유효할 때만 ready가 되도록 했다.
- Main과 Fast Control의 검증된 연속성 merge 및 중단된 Fast action 복구 경계를 구현했다.
- 기억 문맥을 raw turn·파생 provenance에 연결하고 근거 없는 기억은 모델 입력에서 보류했다. 사용자 확인 기억의 저장·회수·삭제 lifecycle과 답변 없는 음성 턴 보존도 검증했다.

### 증거 범위

- `source/offline`: source, 격리 이미지와 process 회귀를 통해 continuity, action recovery, memory lifecycle을 검증했다.
- `local live`: 일부 Bot API와 Control Page만 비파괴 배포했다.
- `external 미검증`: 실제 Discord bot, 마이크, 스피커, Minecraft와 무거운 모델은 시작하지 않았다.

### 재사용 가능한 배움

- HTTP 응답은 liveness일 뿐 기능 readiness가 아니다. 실제 행동에 필요한 의존성과 effect 증거를 다시 계산해야 한다.
- 외부 전달과 내부 저장 사이에 실패 가능 작업이 있다면 전달된 사실을 먼저 내구화하고 재시도 가능성을 명시해야 한다.

## ASR 실행 엔진 실측 비교

- 같은 모델의 두 실행 엔진을 순차 측정하고 원 서비스 복구 후 재측정까지 기록했다. 앞선 기준선만 보면 성능 향상으로 보이던 차이가 복구 후 기준선에서는 뒤집혔다. 메모리 절감 관측·속도 우위·출력 일치·음성 정확도는 별도 판정해야 한다. 상세 원본: Evelyn `docs/worklog/2026-09-11.md`의 Qwen ASR llama.cpp GPU0 실측.
- 후속은 양쪽 캐시 재사용 허용을 확인한 반복 입력 비교로 분리했다. 같은 모델/정밀도/장치라도 실제 캐시 재사용 범위·음성 전처리·API 어댑터는 다르므로 실용 backend 비교와 순수 연산 kernel 비교를 구별한다. 상세 원본: Evelyn `docs/worklog/2026-09-11.md`의 Qwen ASR 엔진 단독 비교 재검증.

## 실행 엔진 전환의 호환 경계

- 같은 모델을 유지해도 새 엔진의 전체 응답과 기존 wrapper의 생성된 나머지 응답은 다른 계약이다. 정확한 prefix 변환, 재시작 중 stream 등록 경쟁, 추론 중 health 응답을 각각 회귀로 확인했다. 소스 검증과 실제 음성 수용은 구별한다. 상세 원본: Evelyn `docs/worklog/2026-09-11.md`, `evelyn_core/runtime/evelyn_core/stt_llamacpp_backend.py`.

## 이미지 크기와 실제 모델 입력 비용

- CPU 합성 전처리 확인에서 입력 파일을 축소해도 모델 processor가 재확대하여 내부 crop 수가 그대로인 경우를 확인했다. 최적화는 파일 해상도뿐 아니라 processor 출력 tensor·image token 수까지 추적해야 하며, 이 수치 감소도 실제 인식 품질이나 GPU 지연 개선과는 별도 검증이다. 상세 원본: Evelyn `docs/worklog/2026-09-11.md`의 Vision 조사 결과.
- 기존 도구 선택이 공용 호출부에 전달되지 않아 장면 요청에도 OCR 기본값이 적용되던 연결을 수정했다. 옵션별 실제 호출과 실패 증거를 회귀로 확인했으며, source 통과와 실측 성능 개선은 구분한다. 상세 원본: Evelyn `docs/worklog/2026-09-11.md`의 Vision V1.

## 출력용 CAD와 실물 적합성의 검증 분리

- 일체형 어댑터의 STEP·STL을 재개방해 단일 솔리드, 치수, 실제 나선 피치·방향과 메시 건전성을 확인했다. 스플라인의 일반 경계 상자는 실제 표면보다 커질 수 있어 정밀 경계 및 메시 정점과 대조했다. 출력 공차·접착·하중은 별도 실물 검증으로 남겼다. 상세 원본: 로컬 CAD 어댑터 프로젝트 `outputs/plan.md`, `outputs/사용안내.md`.
- 후속 실물 피드백으로 기존 출력 권장을 철회하고 공차와 수평 출력 좌표를 수정했다. 본체와 별도 체결 시험편의 실제 나사 메시가 일치함을 확인했으며, 지름 보정이나 CAD 통과를 강도 개선으로 표현하지 않았다. 상세 원본: 같은 프로젝트 `outputs/plan.md`, `outputs/v2/사용안내_v2.md`.

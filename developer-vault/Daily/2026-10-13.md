## H3 기본 캐릭터 및 2-GPU 분리 설치 — 기본 실행 검증 완료

- 승인된 전체 영상 가중치와 공식 4비트 입력 모델의 게시자 크기·해시를 확인했다. 대기열이 비었을 때 해당 작업 서버만 재시작하여 5090=영상 생성, 3090=입력·영상/오디오 변환 구성으로 적용했다. 기존 모델·워크플로·제공 원본 참조는 보존 검사를 통과했다.
- 실제 브라우저 Run으로 새 구성의 텍스트 영상과 고정 참조 캐릭터 영상 각 1건을 생성했다. 124프레임/24fps/약5.17초/스테레오 MP4 디코딩 및 오디오 신호 확인. 새 연결·다시 열기에서 참조3개와 간단 입력 기본값 유지, 누락 오류 없음 확인.
- 기본 이미지 로더의 파일 목록 범위와 참조 기본값을 맞추고, 중복 연결 및 장치 선택 우회 음성 대조를 적용했다. 런처는 포트 번호만이 아니라 정확한 실행 인자와 두 장치 이름을 확인한다. 독립 검토에서 발견한 중복 연결·실행 인자 오탐을 수정하고 해당 경로 재검사를 통과했다.

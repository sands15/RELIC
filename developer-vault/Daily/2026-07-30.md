# 2026-07-30

## [[Projects/Evelyn|Evelyn]]

### 결과

- 단기 대화 연속성, 자율행동 승인과 Minecraft world action을 각각 durable owner와 fail-closed lease에 결박했다.
- 기억 삭제가 원본뿐 아니라 파생 기억·인덱스·캐시까지 정리되고 프로세스 강제 종료 뒤에도 이어짐을 별도 프로세스 테스트로 검증했다.
- Windows Host runtime을 재현 가능한 lock으로 고정하고 local-only readiness checker를 통과했다.
- 화면 답변을 fresh host evidence에 결박하고, provenance 감사·수동 repair·conflict-safe correction을 추가했다.
- 로컬 마이크에 세션 한정 명시 동의와 만료·철회 시 물리 OFF 확인 경계를 배포했다.

### 증거 범위

- `local live`: Bot API, Control Page와 Host의 local-only readiness 및 마이크 동의 API의 비활성 상태를 확인했다.
- `source/offline`: crash/restart 삭제 복구, provenance와 owner/lease 경계를 격리 검증했다.
- `external 미검증`: 실제 마이크는 OFF였고 Discord 음성·Minecraft 세션은 실행하지 않았다. 화면의 실제 관찰 내용은 개인 기록에 복사하지 않는다.

### 재사용 가능한 배움

- 영구 삭제는 원본 파일만이 아니라 파생물·인덱스·캐시의 lineage와 crash 이후 복구까지 포함해야 한다.
- 동의가 필요한 입력 장치는 논리 상태만 OFF로 바꾸지 말고 현재 세대의 물리 정지 증거까지 확인해야 한다.

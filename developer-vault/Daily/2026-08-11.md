# 2026-08-11

## [[Projects/Bambu Support Profile Automation|Bambu Support Profile Automation]]

### 결과

- 기준 Bambu Studio preset의 support 설정을 새 `.3mf` 파일에 적용하는 PowerShell 도구를 구현했다.
- 원본을 보존한 채 임시 복사본을 수정하고 고유한 출력 이름으로 교체하는 처리와, 불완전한 다운로드를 건너뛰는 안정화 대기·single watcher mutex를 추가했다.
- SendTo launcher와 시작 프로그램 watcher 설치 흐름을 만들고 로컬 설치·출력 열기까지 확인했다.

### 증거 범위

- `local source`: 적용 스크립트와 설치 launcher가 현재 남아 있음을 확인했다.
- `historical local verification`: 테스트용 3MF 처리와 설치 후 결과 화면 확인이 Codex 작업 기록에 남아 있다.
- `제외`: 실제 3MF 모델, 개인 preset 값, 화면과 사용자 환경 경로는 기록하지 않았다.
- `한계`: Git commit이 없는 로컬 자동화이며 Bambu Studio의 모든 버전·파일 형식을 보장하지 않는다.

### 재사용 가능한 배움

- 다운로드 감시 자동화는 파일 생성 이벤트만 믿지 말고 크기·수정 시각이 안정된 뒤 처리하며, 원본 보존과 atomic output을 기본 계약으로 둬야 한다.

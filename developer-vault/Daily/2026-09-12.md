# 2026-09-12

## 검색 알고리즘과 전체 경로의 비교

- 합성 입력으로 native 벡터 검색을 기존 구현과 비교하고, 단순한 배열 기반 정확 검색을 대조군으로 두어 자료 표현 비용과 탐색 알고리즘 효과를 분리했다. 후보 검색의 큰 개선이 전체 검색에 그대로 적용되지는 않았고, 목표 회수율 설정도 실제 회수율을 보장하지 않았다. 성능은 전체 호출 경계와 실제 결과 누락을 함께 측정해야 한다. 원본: Evelyn `tools/benchmark_memory_quake.py`, `docs/worklog/2026-09-12.md`. 실제 사용자 기억 품질·운영 통합은 별도다.

## 지연 계측의 실패·전달 경계

- 오프라인 합성 진단에서 성공 경로에만 시간이 남고 실패에는 빠지는 계측을 확인했다. 처리기 내부 시간은 요청 대기·응답 전달을 포함한 사용자 지연과 다르며, 숫자 필드 추가도 엄격한 응답 계약에서는 호환성을 깨뜨릴 수 있다. 상세 원본: Evelyn `docs/worklog/2026-09-12.md`. 실제 성능 측정이나 구현 완료로 보지 않는다.
- 이후 승인된 계측 구현을 기존 응답 계약을 유지한 채 통합하고 오프라인 회귀·독립 검토를 마쳤다. 취소된 await 뒤에도 내부 thread는 파일을 만들 수 있으므로 작업 종료·소유권 등록·정리를 확인해야 하며, 뒤늦은 worker 오류가 원래 취소를 덮지 않는지도 검증했다. 상세 증거: Evelyn `docs/worklog/2026-09-12.md`; 실제 화면/GPU 성능·운영 배포는 별도다.

## Vision 전처리의 실제 입력 예산

- 기존 설치된 전처리기를 합성 입력으로 실행해 외부 이미지 축소와 모델 내부 resize·patch 분할이 별개임을 확인했다. 해상도 최적화는 파일 크기만 보지 말고 실제 tensor 크기와 처리 조각 수까지 확인해야 한다. 처리량 감소를 인식 품질이나 전체 응답 개선으로 간주하지 않는다. 상세 근거: Evelyn `docs/worklog/2026-09-12.md`; 실제 사용자 화면·GPU 품질 비교는 미완료다.

## 게임 업데이트의 수식 검증

- Sephiria Optimizer 신규 아이템 지원 배포본을 오프라인 검증했다. 능력치 증폭·전환·동률 처리처럼 연산 순서가 중요한 모델은 실제 게임 클래스의 격리 입력 결과와 대조하면 합성 테스트만으로 놓치는 경계를 확인할 수 있다. 조건부 발동 효과와 상시 DPS는 구분한다. 원본: Sephiria Optimizer `plan.md`, `tests/Test-UpdatedCapture.ps1`. 실제 플레이 검증은 다음 설치 단계에 남아 있다.
- 후속 점수·유일 효과 소유권 오류를 실패 재현 후 수정하고 v0.4.5 배포본을 오프라인 검증했다. 집계 필드는 점수 계산 전에 채우고, 기존 소유자의 무효화는 대체 소유자를 선택하기 전에 완료해야 순회 순서에 따른 누락을 막을 수 있다. 원본: Sephiria Optimizer `plan.md`, `tests/UpdatedItemsTest.cs`. 게임 설치·실제 플레이 확인은 별도다.
- 이후 사용자 요청으로 v0.4.5를 설치하고 이전 파일 백업, 설치본 버전·해시 일치와 자체 검사 통과를 확인했다. 실제 게임 내 로드는 다음 실행 때 확인한다. 원본: Sephiria Optimizer `plan.md`의 Installation 기록.

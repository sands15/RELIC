# 2026-09-03

## [[Projects/Evelyn|Evelyn]]

### 결과

- 개인 Local Voice의 목표를 마지막 음성 뒤 300ms soft endpoint와 추가 500ms reopen으로 동결했다.
  grace 안 재입력은 같은 PCM·ASR session의 한 발화로 처리하며, 현재 500ms hard endpoint는 구현·검증
  전까지 유지한다.
- 300ms 시점의 계산은 side-effect-free prepare로 제한하고, authoritative final과 exact binding이
  일치할 때만 accepted user turn을 승격하도록 했다. 구현·테스트·실제 장치 검증은 후속 범위다.

### 재사용 가능한 배움

- 비동기 요청 취소는 이미 기록되거나 외부로 전달된 효과의 rollback이 아니다. 늦은 입력을 합치는
  최적화는 계산 단계와 commit 단계를 분리하고, 재입력에는 임시 계산만 폐기해야 한다.

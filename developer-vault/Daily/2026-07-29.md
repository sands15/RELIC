## [[Projects/Evelyn|Evelyn]]

### 결과

- 마이크 입력부터 STT, 대화, TTS와 재생까지 단계별 증거로 판정하는 Voice P0 검증 프레임워크와 Host Supervisor를 구현했다.
- 기억 provenance, 삭제 preview/apply, tombstone과 인덱스·캐시 정리 계약의 초기 버전을 구현했다.
- 저장공간 retention 보고, 고정 오류 관측과 dependency/config 보호 경계를 추가했다.

### 증거 범위

- `source/offline`: 검증 프레임워크, 기억 삭제 계약과 관련 테스트를 구현·검증했다.
- `local live`: dependency/config 변경의 제한된 runtime smoke만 별도 확인했다.
- `external 미검증`: Voice P0는 검증 시스템 구현 상태였으며 실제 마이크·스피커·Discord E2E 성공은 아니었다. 같은 checkpoint의 Mindcraft·Fast Control 통합도 전체 live 완료로 보지 않는다.

### 재사용 가능한 배움

- 검증 장치를 구현한 사실과 사용자가 실제 환경에서 성공한 사실은 서로 다른 이정표다.
- 민감한 기능은 성공률 측정 전에 저장 범위, 삭제 경로와 공개 오류 형식을 먼저 계약으로 고정해야 한다.

# 2026-11-06

## 로컬 게임 영어 음성 설정 — 실제 적용 실패 확인

전날 영어 음성 설정값 저장은 검증됐지만, 사용자가 실제 실행에서 외국인 등장인물까지 한국어로 말한다고 확인했다. 저장값은 실행 후에도 유지됐고 게임과 같은 Windows 읽기 방식으로도 정상 반환됐다. 별도 프로필 언어로 실행 인수를 만드는 경로를 확인했으나, 실행 중 선택값은 아직 관측하지 못해 원인은 미확정이다. 원본은 Codex의 2026-11-05 Call of Duty 작업 `work/korean-pilot/task.md#english-voice-runtime-failure-20261106`다.

[[Learnings/Evidence scope is part of the result]]에 따라 설정 저장 PASS와 실제 음성 전환 FAIL을 분리했다. 추가 파일 변경이나 게임 실행은 하지 않았다. 다음 확인은 사용자가 실행한 게임의 실제 언어 선택값을 읽어 설정 우선순위 가설을 검증하는 것이다. 현재 한국어 자료와 기존 실패 복구 상태는 유지한다.

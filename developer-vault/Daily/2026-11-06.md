# 2026-11-06

## 로컬 게임 영어 음성 설정 — 초기 실패와 후속 사용자 확인

전날 영어 음성 설정값 저장은 검증됐지만, 사용자가 실제 실행에서 외국인 등장인물까지 한국어로 말한다고 확인했다. 저장값은 실행 후에도 유지됐고 게임과 같은 Windows 읽기 방식으로도 정상 반환됐다. 별도 프로필 언어로 실행 인수를 만드는 경로를 확인했으나, 실행 중 선택값은 아직 관측하지 못해 원인은 미확정이다. 원본은 Codex의 2026-11-05 Call of Duty 작업 `work/korean-pilot/task.md#english-voice-runtime-failure-20261106`다.

[[Learnings/Evidence scope is part of the result]]에 따라 설정 저장 PASS와 실제 음성 전환 FAIL을 분리했다. 추가 파일 변경이나 게임 실행은 하지 않았다. 후속 실행에서는 사용자가 영어 음성으로 들린다고 확인했다. 한국어 메뉴와 영어 음성 옵션 켜짐도 화면에서 확인됐으며, 이 사이 에이전트의 추가 게임 자료·설정·실행 방식 변경은 없었다. 현재 요청 범위는 사용자 확인 수준에서 완료됐다. 앞선 실행과 달랐던 이유는 확정하지 않았고 전체 캠페인 재생도 검증하지 않았다. 현재 설정과 기존 실패 복구 상태를 유지하고 추가 조사는 멈췄다.

## Evelyn Control Page — 역방향 프록시 뒤에서 "이 PC" 판정은 Host가 아니라 도착 포트로

Evelyn Control Page는 loopback `Host`를 "이 PC 브라우저"의 증거로 썼다. 그런데 Tailscale Serve는 클라이언트가 보낸 `Host`를 그대로 넘기고, Docker NAT는 로컬과 프록시 연결의 상대 주소를 같게 만든다. 그래서 tailnet의 다른 기기가 `Host`만 바꿔 소유자 로그인 검사를 건너뛸 수 있었다. 고친 방식은 프록시 전용 리스너 포트를 따로 두는 것이다. 소켓이 도착한 포트는 헤더로 위조할 수 없다. 메모리 서버 재현 시험이 수정 전에는 실패하고 수정 후 통과했다. 같은 날 라이브에 적용해 이 호스트에서 위조 `Host`가 403이 되는 것을 확인했다. 다른 기기에서의 실제 시도는 하지 않았다. 원본은 Evelyn `docs/worklog/2026-11-06.md#tailnet-host-spoof-fix-20261106`이다.

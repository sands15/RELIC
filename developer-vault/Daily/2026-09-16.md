# 메시 변형 검증과 검색 근거 구분

- 입력 예산에는 본문뿐 아니라 제목·출처·규칙도 들어간다. 같은 질문이 여러 기억을 요구하는 통제 시험에서 검색 개수 축소는 크기를 줄여도 필요한 근거를 누락했고, 단일 장문은 개수를 줄여도 한도를 넘었다. 형식 비용과 본문 자체의 초과를 먼저 분리해야 한다. 근거: Evelyn `docs/worklog/2026-09-16.md`의 P70 CPU 진단. 의미 정확도나 운영 성능 측정은 아니다.

- 검색된 원문과 근거 ID가 맞아도 모델 입력을 앞부분만 잘라 만들면 뒤쪽 정정이 사라질 수 있다. 실제 전달 경계에서 이를 재현해 예산 내 본문을 보존하고, 한도 초과는 명시적으로 보류하도록 수정했다. 검색 장애도 정상적인 빈 결과와 구별했다. 회귀 통과는 장문 전체 활용이나 실제 답변 품질의 증명이 아니다. 근거: Evelyn `docs/MEMORY_PROVENANCE_DELETION_CONTRACT.md`, `docs/worklog/2026-09-16.md`의 P69 source/offline 기록.

- 기억 검색의 후보 포함률과 최종 답의 정확도를 분리해 확인했다. 작은 합성 집합에서 후보 확대가 누락을 없애도 무관한 후보까지 반환하면 최종 정확도는 악화됐다. 평가자만 아는 개인 관계를 맞히는 것은 저장된 근거로 확인한 성공과 다르다. 근거: Evelyn `docs/worklog/2026-09-16.md`. 재사용 개발세트의 CPU 진단이며 운영 품질·일반화 검증이 아니다.
- 후속 로컬 모델 시험에서는 문서의 의미 분류와 AND/OR/제외 연산을 분리하자 동결된 작은 새 주제 집합의 선택 성공이 개선됐다. 없는 근거를 추가로 제공한 조건은 최초 검색과 별도로 집계해야 하며, 이 결과는 자동 확인 질문이나 운영 품질을 증명하지 않는다. 근거: Evelyn `docs/worklog/2026-09-16.md`의 P61/P62 기록.
- 확인 질문 실험에서는 “단어 뜻이 불명확함”과 “그 주제의 기억이 없음”을 혼동하면 불필요한 질문이 늘었다. 동일 입력에 다른 숨은 의도를 부여한 대조에서는 추가 정보 없이 두 의도를 구별할 수 없음을 검산했다. 이는 정보 부재와 모델의 원문 조건 판정 오류를 분리하는 근거이지 실제 모델 정확도의 증명이 아니다. 재사용 합성 자료의 성공과 일반 검색 품질을 구별해 미달 결과를 보존했다. 근거: Evelyn `docs/worklog/2026-09-16.md`의 P63–P68 기록. 운영 적용이나 실제 사용자 대화 검증은 아니다.

- 기존 홈을 둔 채 새 홈만 빼면 필요한 벽이 복원되지 않는다. 기준 형상이 요구하는 재료를 먼저 채우고 새 홈을 가공해야 한다. 또 삼각형 꼭짓점만 비선형으로 옮기면 닫힌 메시에서도 면 교차가 새로 생길 수 있다. 변형 경계에서 면을 분할하고 각 구간에 일관된 선형 변형을 적용한 뒤, 변형 전후의 실제 교차를 비교해 추가 교차가 없음을 확인했다. 삼각형 목록 방식의 메시 생성과 인덱스 방식의 생성에서 작은 면 보존 결과가 달라, 최종 내보내기와 재로드도 별도로 확인해야 한다. 근거: Joycon2 수정 작업 `outputs/plan.md`, `outputs/joycon2_repair_v3/grow_source.py`, `work/joycon2_repair_review_v3_pwl_crossings.json`. 형상 처리의 검증 결과이며 전체 조립·출력 성공을 뜻하지 않는다.
- 좌우 부품을 재사용할 때는 원본을 반전해 겹쳐 보고 결합면의 차이를 따로 측정한다. 외관상 대칭인 원본에도 작은 차이가 있었으며, 수정한 한쪽 전체를 반전한 뒤 반대쪽 버튼·연결판의 간섭을 다시 확인했다. 글자와 로고는 반전 대상에서 분리해 읽는 방향을 보존했다. 근거: 같은 작업의 `outputs/plan.md`, `work/joycon_original_symmetry_review.json`, `work/joycon2_right_mirror_review.json`. 표면 표본과 제한된 동작 위치의 형상 검증이며 실물 작동 보증은 아니다.
- 조립체 전체의 비율은 공통 좌표계에서 같은 배율을 적용하고 검사해야 보존된다. 버튼 접촉 끝단은 원본 형상 그대로 이동하고 연결부만 연장했으며, 저장 메시·실제 STL·슬라이서 3MF의 형상 일치와 출력 방향을 각각 확인했다. 근거: Joycon2 수정 작업 `outputs/plan.md`, `work/joycon3_final_acceptance_reconciliation_review.json`, `work/joycon3_bambu_v6_review.json`. 측벽 표본 검사와 파일 재로드는 실물 장착·작동 검증을 대신하지 않는다.
- 어댑터 수정판의 끼움은 사용자 실물 확인에서 테이프 보정을 포함해 수용됐다. 치수를 다시 바꾸지 않고 보정 조건을 기록했으며, 끼움 수용과 나사·하중 내구성 확인을 구별했다. 근거: 로컬 CAD 어댑터 프로젝트 `outputs/plan.md`의 실물 확인 기록.

# 2026-11-10

## Evelyn Mind — 컨테이너 안의 마음은 PC를 읽지 못한다, 그리고 "빼기"보다 "자리표시"

이블린이 매 턴 시각을 알고, 물으면 PC 정보를 로컬에서만 답하게 했다. 설계가 승인된 뒤 계획을 쓰려고 코드를 읽다가 전제 두 개가 틀린 것을 찾았다.

- 마음은 Docker 컨테이너에서 돈다. 그래서 거기서 OS와 이름을 읽으면 컨테이너의 Linux 정보가 나온다. PC 정보는 PC에서 직접 도는 몸(body-local)이 연결 인사(`hello`) 때 알려 주게 바꿨다.
- 비밀 답을 기록에서 그냥 빼면, 다음 턴 모델은 답 없는 질문만 보게 된다. 그러면 작은 모델이 답을 지어낼 수 있다. 그래서 답이 있었다는 자리표시만 남겼다.

배운 점은 세 가지다.

- 값을 "어디서 읽느냐"는 실행 위치(컨테이너인지 호스트인지)부터 확인한다.
- 프롬프트에서 무언가를 숨길 때는 빈자리가 모델에게 어떻게 보일지도 설계한다.
- prefix cache를 지키려면 바뀌는 값(시각)은 프롬프트 맨 끝 메시지에만 둔다.

또 Python 3.11의 `platform.release()`는 Windows 11에서도 "10"을 돌려준다. 그래서 빌드 번호(22000 이상)로 구분해야 한다.

증거 수준: source 시험(좁은 회귀 1524개 통과)과 body-local 인터프리터에서 한 실제 읽기다. 실제 기동과 음성은 미검증이다.

## LoL helper — OCR 연산 소폭 최적화

정확도 우선 결정을 유지해 색상·회색 두 보기 판독을 보존하고, OCR 디코더에서 이미 계산한 선택 점수를 재사용하도록 최적화했다. 합성 입력에서 출력당 0.94ms에서 0.18ms로 줄었고, 관련 검사 217개와 설치 OCR 파일 Defender 검사를 통과했다. 앱은 한 번 시작했으나 후속 조회에서 프로세스가 보이지 않아 계속 실행과 창 표시, 종료 원인은 확인하지 못했다.

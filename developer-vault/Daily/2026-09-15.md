# 메시 각인과 원형 보존

- 기존 각인에서 필요한 글자 윤곽을 직접 추출하면 폰트를 추측하지 않고 같은 서체를 재사용할 수 있다. 큰 메시 전체를 다시 만들기보다 작은 각인 면만 교체하고 주변 삼각형과 경계 꼭짓점을 보존하는 방식으로 변경 범위를 검증했다. 원본 결함과 새 결함을 구분하고, 반대편 부품의 읽는 방향은 공통 좌표계의 그림만으로 판단하지 않는다. 근거: Joycon 각인 작업 `outputs/joycon_siro/independent_review.json`, `outputs/joycon_siro/native_load.json`, `outputs/plan.md`. 형상·파일 불러오기 검증이며 실제 출력 검증은 아니다.

- 서로 비슷해 보이는 좌우 형상도 원본을 각각 보존해야 한다. 장착 홈을 다른 모델에서 가져올 때는 한 단면이나 위쪽 벽 폭만 보지 않고, 아래쪽으로 넓어지는 홈까지 전체 곡면이 가공 범위에 포함되는지 검사해야 한다. 연속적인 면 검사와 실제 내보낸 메시 검사를 나누어 수행했다. 근거: Joycon2 맞춤 작업 `outputs/plan.md`, `work/joycon2_independent_blank_coverage.json`. 실물 체결 검증과는 별개의 형상 검증이다.
- 장착 홈의 직각 절단 자국을 다듬을 때는 바닥 윤곽만으로 가공 범위를 줄이면 위쪽 고정 벽을 놓칠 수 있다. 바닥과 안쪽 벽을 함께 감싸는 보수적 윤곽을 사용하고, 실제 내보낸 메시에서 각인 이동·기존 손잡이 보존·연결판과 버튼 간섭을 확인했다. 근거: Joycon2 경계 마감 `outputs/joycon2_finish_v2/independent_review.json`, `outputs/joycon2_finish_v2/native_load.json`, `outputs/plan.md`. 형상 및 기본 로더 검증이며 실물 동작 검증은 아니다.

# 2026-09-02

## [[Projects/Evelyn|Evelyn]]

### 결과

- Discord live 검증 전 보안 preflight에서 두 대상 volume이 필수 암호화 조건을 충족하지 않아 test archive
  provision이 생성 전에 fail-close했다. live service와 production archive는 시작하지 않았다.
- cleanup이 불확실할 때 command recovery ledger를 보존하도록 live launcher를 보강하고 관련 회귀를 통과시켰다.
- 기존 Markdown 명시적 기억을 격리된 임시 저장소에서 저장하고 새 프로세스로 회상한 뒤 삭제·재시작 비회상까지
  검증했다. 실제 기억 내용과 외부 서비스는 사용하지 않았다.

### 재사용 가능한 배움

- live 검증은 서비스 기동보다 보안 전제조건을 먼저 확인하고, cleanup이 불확실하면 복구 근거를 지우지 않아야 한다.
- 미완료 계획 항목을 현재 사용자 우선순위로 추정하지 않는다. 기존 기능이 목적을 충족하는지 먼저 확인하고,
  선택형 저장소·보안 설정·외부 효과는 필요성을 명시적으로 확인한 뒤 진행한다.
- 개인 기억 검증은 비민감 synthetic 문구·임시 저장소·새 프로세스 경계로 수행하면 실제 데이터를 건드리지 않고
  저장 내구성, 소유 범위, 삭제 후 비회상을 함께 확인할 수 있다.

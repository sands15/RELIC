## [[Projects/Toss Trading Bot|Toss Trading Bot]]

### 결과

- 잠긴 장전 계획의 한 종목만 받는 독립 뉴스 worker를 구현해 Finnhub 수집, 선택형 local LLM 검증, 뉴스 전용 Discord 전달을 거래 package·DB·자격증명과 분리했다.
- context 경합·조기폐장, 거래 DB 무변경, 세션 만료, 악성 LLM fallback, Discord 재시작 재전송을 포함한 전체 회귀 `372 passed`를 확인했다. 실 API·Mac 상시 운용·실주문은 아직 검증하지 않았다.
- Mac 운영 노드의 Tailscale 네트워크와 native OpenSSH 공개키 접속을 검증했다. 동시에 정본 불일치, 절전으로 인한 연결 단절, live-capable 설정, 상태 DB 무결성 실패를 확인해 배포와 외부 호출 테스트를 계속 차단했다.
- Discord Developer Portal의 기존 앱을 `주식 거래 승인 봇`으로 정리해 공개 봇과 사용자 설치를 끄고 서버 설치만 허용했으며, 기본 설치 링크와 세 privileged intent를 비활성화했다. 서버 설치·토큰 배치·실제 interaction E2E는 아직 하지 않았다.

### 재사용 가능한 배움

- 설명용 AI의 비영향성을 보장하려면 prompt만 제한하지 말고 독립 import graph, 최소 context DTO, 별도 state/webhook, 위험 환경변수 거부를 함께 계약 테스트로 고정한다.
- 외부 서비스에 idempotency key가 없으면 로컬 dedupe가 있어도 성공 응답 유실 중복은 남으므로 전달 계약을 at-least-once로 기록한다.
- 자동매매 노드의 배포 준비성은 코드 테스트만이 아니라 exact source revision, DB integrity, fail-safe runtime flags, 전원·절전·재부팅 복구를 함께 증명해야 한다.

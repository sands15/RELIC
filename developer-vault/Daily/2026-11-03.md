# 2026-11-03

## Evelyn Discord 작업자를 마음의 몸으로

Discord 작업자를 빼지 않고 body-local과 같은 규칙의 몸으로 얇게 만들었고, 리뷰가 확인한 결함 36건과 재리뷰 27커밋을 수리했다. 전체 회귀는 524모듈·6,787테스트 나쁜 결과 0이고 이미지는 빌드·import까지 확인했다. 실제 Discord·마이크·이 코드의 스택 기동은 하지 않았다. 원본은 프로젝트 `docs/worklog/2026-11-03.md#discord-thinning-wave7-20261103`.

재사용 가능한 교훈: (1) 리뷰 뒤에 만든 수리 커밋은 첫 리뷰를 받지 않은 새 코드다. 다시 리뷰했더니 확인 없이 영원히 기다리는 보내기, 나이 제한 없는 대기, 60초 길이 문장에서 나는 KeyError가 나왔다. (2) 기본 파일을 읽도록 바꾼 설정은 테스트가 실제 서비스에 닿는지 가짜 청취기로 직접 확인한다. 토큰 기본 파일을 읽게 하자 테스트가 실행 중인 마음에 인증해 접속했다. (3) 컨테이너 켜기 명령은 실행기를 스텁한 테스트로는 못 잡는다. 실제 인자를 compose config로 로드해 보니 Compose 5.x에서 프로젝트가 로드되지 않았다. (4) 작업 트리를 나눠 쓰는 저장소에서는 에이전트에게 git stash를 금지한다. 한 에이전트가 깨끗한 트리에서 stash pop을 해 다른 브랜치의 stash를 꺼냈다.

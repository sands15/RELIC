# 2026-11-03

## Evelyn Discord 작업자를 마음의 몸으로

Discord 작업자를 빼지 않고 body-local과 같은 규칙의 몸으로 얇게 만들었고, 리뷰가 확인한 결함 36건과 재리뷰 27커밋을 수리했다. 전체 회귀는 524모듈·6,787테스트 나쁜 결과 0이고 이미지는 빌드·import까지 확인했다. 소유자 지시로 실험 브랜치에 합쳐(전체 회귀 7,116테스트 나쁜 결과 0) 재빌드 기동했고 닥터 live 2회가 FAIL 0이다. 실제 Discord·마이크는 하지 않았다. 원본은 프로젝트 `docs/worklog/2026-11-03.md#discord-thinning-wave7-20261103`.

재사용 가능한 교훈: (1) 리뷰 뒤에 만든 수리 커밋은 첫 리뷰를 받지 않은 새 코드다. 다시 리뷰했더니 확인 없이 영원히 기다리는 보내기, 나이 제한 없는 대기, 60초 길이 문장에서 나는 KeyError가 나왔다. (2) 기본 파일을 읽도록 바꾼 설정은 테스트가 실제 서비스에 닿는지 가짜 청취기로 직접 확인한다. 토큰 기본 파일을 읽게 하자 테스트가 실행 중인 마음에 인증해 접속했다. (3) 컨테이너 켜기 명령은 실행기를 스텁한 테스트로는 못 잡는다. 실제 인자를 compose config로 로드해 보니 Compose 5.x에서 프로젝트가 로드되지 않았다. (4) 작업 트리를 나눠 쓰는 저장소에서는 에이전트에게 git stash를 금지한다. 한 에이전트가 깨끗한 트리에서 stash pop을 해 다른 브랜치의 stash를 꺼냈다.

## Evelyn 대화가 이상한 원인 진단

"사람처럼 살기" 프롬프트 두 줄을 넣은 뒤 대화가 어색해졌다. 같은 프롬프트 조립으로 실제 Main에 장면마다 8회 다시 보내 이전 프롬프트와 비교했다. 인사에 지어낸 활동 먼저 꺼냄 4/8 대 0/8, 예시 단어 "산책" 그대로 7/8, 사용자 말을 자기 얘기로 돌림 6/8 대 0/8이 나왔다. 기억 정리는 지어낸 일상과 이블린의 위로를 사실처럼 적었다. 일일 노트 쓰기 실패는 로그 없이 삼켜져 긴 발화 1턴이 사라졌다. 수리는 하지 않았다. 원본은 프로젝트 `docs/worklog/2026-11-03.md#control-page-odd-dialogue-20261103`.

재사용 가능한 교훈: (1) 프롬프트를 바꾸면 바꾸기 전과 같은 장면을 여러 번 돌려 비교한다. 단, 온도 0.7에서 8회는 실행마다 크게 흔들렸다(같은 프롬프트로 6/8 → 1/8). 원인을 가리는 판단은 20회 이상으로 한다. 정정: 처음 적은 "예시 단어를 그대로 고른다"는 틀렸다. 예시를 빼도 산책이 6/8로 남았다. (2) 상태 없이 "지어내도 된다"고 허락하면 세부 질문에서 무너지고, 그 말이 기억 정리를 거쳐 사실로 굳는다. (3) 쓰기 경로가 예외를 삼키면 "성공" 보고와 실제 저장이 갈라진다. 원본과 파생 기록의 턴 id를 맞대 보면 드러난다.

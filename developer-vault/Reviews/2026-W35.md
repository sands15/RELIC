# 2026-W35 주간 개발 회고

8월 24~28일의 Evelyn, RELIC과 Toss Trading Bot 작업을 포함한 부분 회고다.

## 검증된 결과

- **2026-08-25~27 — Main→TTS-ready 성능 후보를 고정 하네스에서 검증했다.** GPU architecture에 맞는 runtime identity를 고정하고 graph-on 후보의 지연 개선과 출력 동등성을 확인했다. **범위: controlled live Docker/GPU 성능 검증, 실제 스피커·Discord·청취 품질과 production 전체 음성 SLO 미검증.** 근거: `docs/worklog/2026-08-25.md`, `docs/worklog/2026-08-27.md`, `docs/MAIN_LLM_LATENCY_TARGET_ARCHITECTURE.md`; commit/checkpoint `d1c8863bc7d338ea6b7ff3013d1e0574dff73e80`.

- **2026-08-27 — 복구 가능한 source 기준선을 고정했다.** 하나의 immutable checkpoint와 clean-clone source 회귀로 복구 가능성을 확인했다. **범위: committed source/offline 검증 완료, production 배포나 remote publish와 무관.** 근거: `docs/worklog/2026-08-27.md`; commit `d1c8863bc7d338ea6b7ff3013d1e0574dff73e80`.

- **2026-08-27~28 — STT image 검증과 Discord corpus 평가를 분리했다.** revised STT는 old/new GPU overlap을 통과했지만 production 승격 조건은 남았고, guided capture는 완료됐으나 모델 진단은 실패했다. 사용자의 수동 선택은 자동 실패 판정을 바꾸지 않았다. **범위: controlled live GPU·Discord transport 검증, corpus promotion과 production 미검증.** 근거: `docs/worklog/2026-08-27.md`, `docs/worklog/2026-08-28.md`, `docs/GPU1_CONCURRENCY_BENCHMARK.md`; commits `d95ea89673772273de5ce8ad44299f921d25c6c3`, `14841a508d881d44585fc07079842fd09aa20acf`, `ee0f2de6a5c46c66255a645b962f5b679f4c775c`, `0f337bec8be627fba5d8851dcdba243afad0d7dc`, `3f84f16f15c86789a8a17ea48575ece079918e28`.

- **2026-08-28 — private archive와 task-guidance 경계를 구현했다.** 기본 OFF archive의 단독 writer·삭제 계보와 bounded task contract·사람 소유 guidance 승격을 기존 구조에 결합했다. **범위: uncommitted source/offline 검증 상태이며 stable project commit, local live, controlled live와 production 모두 미검증.** 설계 기준 commit은 `059843c4051a317558f0aef9bdc9a4ff376f6803`이지만 현재 구현 commit은 없다. 근거: `docs/worklog/2026-08-28.md`, `docs/02_DECISIONS.md`, `plan.md`.

- **2026-08-28 — 개인 개발 기록을 공개 RELIC Vault로 분리했다.** 공개 fail-closed 검사, Markdown 전용 commit과 실제 자동 push를 검증하고 주간 회고 경로를 만들었다. **범위: 로컬 Windows와 공개 Git push 검증, 장기 상주 신뢰성은 별도 재검증 대상.** 근거: [RELIC 초기 Vault commit](https://github.com/sands15/RELIC/commit/de93339343fa3b51cdecd2ffb00d152dd3fcb899), [공개 검사 강화](https://github.com/sands15/RELIC/commit/7c3fc826518da31a826a89c903dd41341a41b228), [실제 자동 push](https://github.com/sands15/RELIC/commit/b2184ae87758875ffaaf3b146a33b94350fa56f6).

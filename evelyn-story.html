Evelyn Local-First Assistant Runtime

Control Page, 로컬 음성, 선택형 Discord, 로컬 모델, 장기 기억과 제한된 도구 실행을 하나의 안전한 흐름으로 연결한 Windows-first 개인 AI 비서입니다.

START

왜 만들었나

텍스트 답변이나 음성 모델 하나를 넘어, 사용자의 입력을 이해하고 기억하며 필요한 작업까지 안전하게 이어가는 로컬 AI 비서를 만들고 싶었습니다. Evelyn은 입력부터 판단, 응답, 복구와 검증까지 전체 시스템을 직접 연결하는 프로젝트입니다.

이 프로젝트를 통해 관심사는 더 분명해졌습니다. 좋은 AI 경험은 모델 성능만으로 만들어지지 않고, 입력 처리, 소유권, 라우팅, 기억, 음성 출력, 지연과 복구가 함께 맞물려야 합니다.

FLOW

시스템 흐름

Evelyn은 텍스트와 음성을 공통 ingress에서 받아 동의·소유권을 확인하고, 필요한 경로만 STT와 local model 또는 제한된 task/tool로 보낸 뒤 전달 결과와 기억을 확정합니다.

  1. Text / Voice Input
  2. Ingress / Consent
  3. STT (Audio Only)
  4. Route / Context
  5. Reply / Task / Tool
  6. Text / TTS
  7. Completion / Memory

직접 다룬 부분

  • Control Page, 로컬 음성, 선택형 Discord ingress를 공통 owner·consent 경계로 연결
  • 짧은 응답, skill, bounded task/tool, local LLM을 조건에 따라 라우팅
  • 확인된 Markdown 기억의 provenance·사용자 범위·수정·삭제 계보 구현
  • content-free trace, durable receipt와 restart recovery로 실패 경계 검증

배운 점
